# Himanshu's Videos

A premium, distraction-free YouTube client for Android. Your feed shows **only** the creators you follow — no recommendations, no trending, nothing else.

- Floating **+** button → paste a channel link, `@handle`, or any video link to follow a creator
- Or share a channel/video from the YouTube app → **Himanshu's Videos** to follow instantly
- Background check every ~15 min → notification with thumbnail when a followed creator uploads
- Filter by creator, or by All / Videos / Shorts. Long-press a creator to unfollow
- Plays in-app with YouTube's official player (fullscreen supported), or jump to the YouTube app

No API key and no login — it uses YouTube's public channel pages and RSS feeds.

Builds automatically on push via GitHub Actions; the signed APK is attached to a release.
